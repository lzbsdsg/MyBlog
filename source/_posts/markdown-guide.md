Markdown 是一种轻量级标记语言，让你专注于内容本身。以下是常用语法速查。
## 标题

使用 `#` 号标记标题，一个 `#` 是一级标题，最多支持六级。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

也可以使用底线形式（仅支持一级和二级）：

```markdown
一级标题
========

二级标题
--------
```

## 文本格式

### 斜体

使用 `*` 或 `_` 包裹文本。

```markdown
*斜体文本*
_斜体文本_
```

效果：*斜体文本*

### 粗体

使用 `**` 或 `__` 包裹文本。

```markdown
**粗体文本**
__粗体文本__
```

效果：**粗体文本**

### 粗斜体

使用 `***` 或 `___` 包裹文本。

```markdown
***粗斜体文本***
___粗斜体文本___
```

效果：***粗斜体文本***

### 删除线

使用 `~~` 包裹文本。

```markdown
~~删除线文本~~
```

效果：~~删除线文本~~

### 下划线

使用 HTML 标签 `<u>`。

```markdown
<u>下划线文本</u>
```

效果：<u>下划线文本</u>

### 高亮

使用 `==` 包裹文本（部分解析器支持）。

```markdown
==高亮文本==
```

### 上标和下标

使用 HTML 标签。

```markdown
上标：X<sup>2</sup>
下标：H<sub>2</sub>
```

### 换行

在行尾添加两个空格，或者使用空行分隔。

```markdown
第一行（行尾有两个空格）
第二行

新段落
```

## 列表

### 无序列表

使用 `-`、`*` 或 `+` 开头。

```markdown
- 第一项
- 第二项
  - 子项 A
  - 子项 B
- 第三项

* 第一项
* 第二项

+ 第一项
+ 第二项
```

效果：
- 第一项
- 第二项
  - 子项 A
  - 子项 B
- 第三项

### 有序列表

使用数字加 `.` 开头。

```markdown
1. 第一项
2. 第二项
   1. 子项 A
   2. 子项 B
3. 第三项
```

效果：
1. 第一项
2. 第二项
   1. 子项 A
   2. 子项 B
3. 第三项

### 任务列表

使用 `- [ ]` 或 `- [x]` 表示未完成和已完成。

```markdown
- [ ] 未完成任务
- [x] 已完成任务
- [ ] 另一个未完成任务
```

效果：
- [ ] 未完成任务
- [x] 已完成任务
- [ ] 另一个未完成任务

## 链接与图片

### 行内链接

```markdown
[链接文本](URL "可选标题")
```

示例：
```markdown
[Google](https://www.google.com "Google 搜索")
```

效果：[Google](https://www.google.com "Google 搜索")

### 引用链接

```markdown
[链接文本][引用标识]

[引用标识]: URL "可选标题"
```

示例：
```markdown
[Google][1]

[1]: https://www.google.com "Google 搜索"
```

### 自动链接

使用尖括号包裹 URL 或邮箱。

```markdown
<https://www.google.com>
<user@example.com>
```

效果：
<https://www.google.com>
<user@example.com>

### 图片

```markdown
![替代文本](图片URL "可选标题")
```

示例：
```markdown
![Logo](https://example.com/logo.png "网站 Logo")
```

### 带链接的图片

```markdown
[![替代文本](图片URL)](链接URL)
```

## 代码

### 行内代码

使用反引号 `` ` `` 包裹。

```markdown
使用 `print()` 函数输出内容。
```

效果：使用 `print()` 函数输出内容。

### 代码块

使用三个反引号 ``` 或缩进四个空格/一个制表符。

围栏式（推荐）：
````markdown
```python
def hello():
    print("Hello, World!")
```
````

效果：
```python
def hello():
    print("Hello, World!")
```

缩进式：

    def hello():
        print("Hello, World!")

支持的语言标识：`python`、`javascript`、`java`、`cpp`、`bash`、`sql`、`html`、`css`、`json`、`yaml`、`markdown` 等。

## 表格

使用 `|` 分隔列，使用 `-` 分隔表头和表体，使用 `:` 控制对齐。

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容1  |  内容2   |  内容3 |
| 内容4  |  内容5   |  内容6 |
```

效果：

| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容1  |  内容2   |  内容3 |
| 内容4  |  内容5   |  内容6 |

对齐方式说明：
- `:---` 或 `---`：左对齐（默认）
- `:---:`：居中对齐
- `---:`：右对齐

## 引用

使用 `>` 符号，支持嵌套。

```markdown
> 这是一级引用
>
> > 这是二级引用
> >
> > > 这是三级引用
```

效果：
> 这是一级引用
>
> > 这是二级引用
> >
> > > 这是三级引用

引用中可以包含其他 Markdown 元素：

```markdown
> ## 引用中的标题
>
> - 列表项
> - 另一个列表项
>
> **粗体文本**
```

## 转义字符

使用反斜杠 `\` 转义特殊字符。

```markdown
\*这不是斜体\*
\[这不是链接\](这不是URL)
\# 这不是标题
```

可转义的字符：
```
\   反斜线
`   反引号
*   星号
_   下划线
{}  花括号
[]  方括号
()  圆括号
#   井号
+   加号
-   减号（连字符）
.   句点
!   感叹号
|   竖线
```

## HTML 支持

Markdown 支持内嵌 HTML 标签。

### 常用 HTML 标签

```markdown
文本颜色：<span style="color: red;">红色文本</span>

居中对齐：<center>居中文本</center>

折叠内容：
<details>
<summary>点击展开</summary>
隐藏的内容
</details>

键盘按键：<kbd>Ctrl</kbd> + <kbd>C</kbd>
```

### 注意事项

- 块级 HTML 标签（如 `<div>`、`<table>`）前后需要空行
- Markdown 语法不会在 HTML 标签内被解析
- 不是所有 Markdown 解析器都支持所有 HTML 标签

部分解析器支持 LaTeX 数学公式。

```markdown
$$

$$
```

## 最佳实践

1. **保持简洁**：Markdown 的核心是易读易写，不要过度使用格式
2. **一致性**：在整个文档中使用相同的标记风格
3. **空行分隔**：段落之间、块级元素之间使用空行分隔
4. **换行**：长行在适当位置换行，便于版本控制和协作
5. **预览**：写作时使用预览功能检查最终效果
6. **兼容性**：注意不同解析器的语法差异，核心语法兼容性最好
