Markdown 是一种轻量级标记语言，让你专注于内容本身。以下是常用语法速查。

## 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本样式

- **粗体** - `**粗体**`
- *斜体* - `*斜体*`
- ~~删除线~~ - `~~删除线~~`
- `行内代码` - `` `行内代码` ``

### 列表

无序列表：
- 项目一
- 项目二
  - 子项目

有序列表：
1. 第一步
2. 第二步
3. 第三步

### 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](https://example.com/image.jpg)
```

## 进阶语法

### 代码块

```python
def hello():
    print("Hello, World!")
```

### 表格

| 功能 | 语法 | 示例 |
|------|------|------|
| 粗体 | `**text**` | **text** |
| 斜体 | `*text*` | *text* |
| 代码 | `` `code` `` | `code` |

### 引用

> 这是一段引用文字。
>
> 可以多行。

### 任务列表

- [x] 已完成的任务
- [ ] 待完成的任务
- [ ] 另一个任务

## 小技巧

1. 使用 `---` 创建分割线
2. 使用 `\` 转义特殊字符
3. 支持 LaTeX 数学公式：$E = mc^2$

---

掌握这些基础语法，就能写出排版优美的文章了。
